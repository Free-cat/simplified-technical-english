# Security

## What the skill runs

The skill has one script, `skills/ste100/scripts/ste_check.py`. It reads one
text file and prints findings. It does not write files, start other programs, or
use the network. It uses the Python standard library only.

## Report a problem

If you find a security problem (for example, instructions that can make an agent
do something unsafe, or a defect in the script), please use
[private vulnerability reporting](https://github.com/Free-cat/simplified-technical-english/security/advisories/new)
and do not open a public issue.

For all other defects, open a normal issue.
