# ASD-STE100 term pack: mechanical equipment, maintenance and manufacturing
#
# This file is NOT part of the official ASD-STE100 Simplified Technical English dictionary.
# It is a project extension listing subject-field words that Issue 9 allows as technical nouns
# (rule 1.5, 22 categories) or technical verbs (rule 1.12, 4 categories) for maintenance
# procedures, shop-floor work instructions and equipment manuals (general machinery, not only aircraft).
#
# Each entry was checked against Issue 9 rules 1.5 to 1.13 and against the dictionary status:
# a word that is APPROVED in the dictionary with a covering meaning is not listed (see the last block).
# Rejected verbs (rule 1.13: names of parts or materials used as verbs, general verbs) are not listed.
#
# A company parts catalog or term base overrides this file. Where they differ, use the company term.
#
# Format (UTF-8), one entry per line, four fields separated by " | ":
#   term | TN or TV | category | std or ext[; note]
#   TN = technical noun (rule 1.5). Category 1 to 22 (rule 1.5 category numbers).
#   TV = technical verb (rule 1.12). Category 1a to 1f (manufacturing), 2c (computer system operations),
#        3a (engineering), 3e (automotive and railway), 3f (energy, oil and gas).
#   std = the word is an example in the standard's own list for that category.
#   ext = project extension by the same principle; the word is not a listed example.
#   note = optional. "general sense: use X" means the word alone is NOT approved in that sense, so a
#          script can warn and suggest the approved alternative. "also called" lists synonyms
#          (rule 1.11): use the first term in the entry and avoid the others.
#   Lowercase terms, except where a capital is part of the name (O-ring). American spelling (rule 1.14).
#   Multi-word terms have at most three words; a hyphenated word counts as one.
#   The same word may appear once as TN and once as TV (for example drill, file, saw).
