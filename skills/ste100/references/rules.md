# ASD-STE100 writing rules (Issue 9, January 2025)

The rule numbers follow Issue 9. The rule text is a summary, not the official
wording. The examples are original. "TN" = technical noun, "TV" = technical verb.

## 1. Words

| Rule | Summary |
|---|---|
| 1.1 | Use only words that are approved in the dictionary, technical nouns, or technical verbs. |
| 1.2 | Use an approved word only as the part of speech that the dictionary gives. |
| 1.3 | Use an approved word only with its approved meaning. |
| 1.4 | Use only the approved forms of verbs and adjectives. |
| 1.5 | A word is a technical noun only if it fits a technical noun category. |
| 1.6 | Use an unapproved word only when it is a technical noun or part of one. |
| 1.7 | Do not use a technical noun as a verb. |
| 1.8 | Use the technical nouns that your company, industry, or subject field approves. |
| 1.9 | When you must select a technical noun, select one that is short and easy to understand. |
| 1.10 | Do not use regional, slang, or jargon words as technical nouns. |
| 1.11 | Do not use different technical nouns for the same thing. |
| 1.12 | A verb is a technical verb only if it fits a technical verb category. |
| 1.13 | Do not use a technical verb as a noun. |
| 1.14 | Use American English spelling unless an official directive tells you differently. |

Examples:

- 1.2 — Not STE: "Test the circuit." (*test* is a noun.) STE: "Do a test of the circuit."
- 1.2 — Not STE: "Oil the bearing." (*oil* is a TN.) STE: "Apply oil to the bearing."
- 1.3 — Not STE: "Follow the aircraft." when you mean "obey". *Follow* means "come after". STE: "Obey the safety instructions."
- 1.6 — "Do not go close to the engine" → "Do not go near the engine." But "close-tolerance bolt" can be a TN if it is the approved part name.
- 1.11 — If the first mention is "access panel", do not write "cover", "door", or "hatch" for the same item later.
- 1.13 — Not STE: "Give the hole a ream." STE: "Ream the hole."

The categories for technical nouns and technical verbs are in `dictionary.md`.

## 2. Multi-word nouns

| Rule | Summary |
|---|---|
| 2.1 | Do not write a multi-word noun (noun cluster) of more than three nouns. |
| 2.2 | If a technical noun has more than three words, write it in full first. Then use a shorter name, or use hyphens to show which words go together. |

- Not STE: "engine fuel pump inlet filter element"
- STE: "the filter element at the inlet of the engine fuel pump"
- 2.2 — "main landing-gear door-retraction winch (the winch)". After that, use "the winch".
- Articles and adjectives do not count; only the nouns in the cluster count.

## 3. Verbs

| Rule | Summary |
|---|---|
| 3.1 | Use only the verb forms that the dictionary gives. |
| 3.2 | Use only: infinitive, imperative, simple present, simple past, simple future. |
| 3.3 | Use the past participle only as an adjective (with a form of BE or BECOME, or before a noun). |
| 3.4 | Do not use helping verbs to make complex verb constructions (perfect, progressive, "would have been"). |
| 3.5 | Use the *-ing* form only as a technical noun or as a modifier in a technical noun. |
| 3.6 | Use the active voice. Procedures: always. Descriptions: as much as possible; the passive is permitted only when the agent is unknown or not important. |
| 3.7 | Use an approved verb to describe an action, not a noun or other part of speech. |

Examples:

- 3.2/3.4 — "The pump has failed" → "The pump failed" or "The pump is unserviceable".
- 3.4 — "The engine is running" → "The engine operates" / "The engine is in operation".
- 3.3 — "The valve is closed" is correct (adjective: state). "The valve was closed by the technician" is passive → "The technician closed the valve."
- 3.5 — "Before removing the cover, …" → "Before you remove the cover, …". But "the operating temperature", "the wiring", "a bearing" are TNs.
- 3.5 — "Using a wrench, tighten the nut" → "Tighten the nut with a wrench."
- 3.6 — "The bolts are to be torqued" → "Torque the bolts." (*torque* as a TV is permitted if your field approves it; if not, "Tighten the bolts to 25 Nm.")
- 3.7 — "Perform the installation of the unit" → "Install the unit." / "Make an adjustment to" → "Adjust".

Modal verbs: CAN and MUST are approved. *Should, may, might, could, would, shall, ought to, need to, have to* are not. Use MUST for an obligation, CAN for a capability or permission, "it is possible that" or "possibly" for a possibility, and "We recommend that" / RECOMMEND for a recommendation.

## 4. Sentences

| Rule | Summary |
|---|---|
| 4.1 | Write short and clear sentences. |
| 4.2 | Do not omit words or use contractions to make sentences shorter. |
| 4.3 | Use a vertical list for complex text. |
| 4.4 | Use connecting words and phrases to connect sentences that have related topics. |
| 4.5 | When applicable, use an article (the, a, an) or a demonstrative adjective (this, these) before a noun. |

Examples:

- 4.2 — "Check valve closed" → "Make sure that the valve is closed." / "Don't" → "Do not".
- 4.2 — "Can be a maximum of 5 mm" → "The gap can be a maximum of 5 mm."
- 4.3 — If a sentence has three or more parallel items or conditions, make a list with a lead-in sentence that ends in a colon.
- 4.4 — Connecting words: *and, but, then, thus, as a result, also, because, if, when, while, after, before, until, unless*. They show the logic that short sentences can hide: "The pressure decreases. As a result, the valve closes."
- 4.5 — "Remove cover from pump" → "Remove the cover from the pump."

## 5. Procedures

| Rule | Summary |
|---|---|
| 5.1 | Write short sentences: 20 words maximum. |
| 5.2 | Write only one instruction in each sentence, unless two or more actions occur at the same time. |
| 5.3 | Write instructions in the imperative (command) form. |
| 5.4 | If you start an instruction with a descriptive statement (a condition or a purpose), divide it from the command with a comma. |
| 5.5 | Write notes only to give information, not instructions. |

Examples:

- 5.2 — "Remove the four bolts and lift the cover and put it on the bench" → three steps.
- 5.2 — Permitted: "Hold the lever and push the button." (same time)
- 5.3 — "The operator should set the switch to OFF" → "Set the switch to OFF."
- 5.3 — "You must now restart the service" → "Start the service again."
- 5.4 — "If the light comes on, stop the pump." / "To release the lock, turn the handle."
- 5.5 — Not STE: "NOTE: Clean the surface before you apply the sealant." That is an instruction; make it a step. STE: "NOTE: The sealant becomes hard in 30 minutes."

Good procedure layout: a numbered step for each action; the result of an action
("The green light comes on.") on a separate line after the step; sub-steps (a, b, c)
when one task has parts.

## 6. Descriptive writing

| Rule | Summary |
|---|---|
| 6.1 | Give the information gradually: one new point at a time, the known before the new. |
| 6.2 | Use key words and connecting phrases to organize the text logically. |
| 6.3 | Write sentences of 25 words maximum. |
| 6.4 | Use paragraphs to show the reader the logical structure of the text. |
| 6.5 | Each paragraph has only one topic. Start with the topic sentence. |
| 6.6 | A paragraph has six sentences maximum. |

- Vary the sentence length. Ten sentences of six words each are as hard to read as one of sixty.
- Not STE: "The hydraulic system, which is pressurized by two engine-driven pumps that are backed up by an electric pump, supplies the flight controls, the landing gear and the brakes, and it is monitored by sensors that send data to the cockpit."
- STE: "The hydraulic system supplies pressure to the flight controls, the landing gear, and the brakes. Two engine-driven pumps pressurize the system. An electric pump is the backup supply. Sensors monitor the system and send data to the cockpit."

## 7. Safety instructions

| Rule | Summary |
|---|---|
| 7.1 | Use an applicable word to identify the level of risk (for example WARNING, CAUTION). |
| 7.2 | Start a safety instruction with a clear and accurate command or condition. |
| 7.3 | Give an explanation that shows the risk or the possible result. |

- WARNING = risk of injury or death. CAUTION = risk of damage to equipment or loss of data. NOTE = information only (rule 5.5). Use the user's standard if they have one (ANSI Z535 and ISO 3864 add DANGER and NOTICE).
- Put a warning or caution before the step that it applies to, not after it and not at the end of the document.
- If a condition must be true before the reader continues, put the condition first.
- Not STE: "WARNING: Extreme care should be exercised, as the fluid is hot."
- STE: "WARNING: DO NOT TOUCH THE FLUID. THE FLUID IS HOT AND CAN CAUSE BURNS."
- STE: "CAUTION: MAKE SURE THAT YOU HAVE A BACKUP BEFORE YOU DELETE THE DATABASE. YOU CANNOT GET THE DATA BACK."
- Capital letters for the full text are a common convention, not a rule. Follow the user's style.

## 8. Punctuation and word counts

| Rule | Summary |
|---|---|
| 8.1 | Use all standard English punctuation marks, but not the semicolon. |
| 8.2 | Use hyphens to connect words that are directly related. |
| 8.3 | You can use parentheses (to make references, to mark list items, to give a short name, to show related information). |
| 8.4 | In a vertical list, a colon has the same effect on the word count as a full stop. |
| 8.5 | Text in parentheses counts as one word in the sentence. (But the text in parentheses must obey the length rule itself if it is a sentence.) |
| 8.6 | Count each of these as one word: a number, a unit of measurement, an identifier, quoted text, an abbreviation or acronym, a title, placard or label text. |
| 8.7 | A hyphenated word counts as one word. |

- 8.6 — "Set the PRESSURE SELECTOR to 25 psi" = 6 words (label = 1, number = 1, unit = 1).
- 8.4 — With a list, count the lead-in as one sentence, and each list item as one sentence.
- For software text, code in backticks, a file path, a URL, and a UI label each count as one word.

## 9. Writing practices

| Rule | Summary |
|---|---|
| 9.1 | Use a different sentence construction when a word-for-word replacement is not sufficient. |
| 9.2 | Use each approved word correctly (obey the dictionary examples). |
| 9.3 | Do not make phrasal verbs from two approved words. |
| 9.4 | When you select terminology or wording, always use a consistent style. |

- 9.1 — "Care must be exercised when handling the unit" → "Be careful when you move the unit."
- 9.3 — *Put out* the fire → "Extinguish the fire." *Carry out* → "Do". *Set up* → "Prepare" / "Install". *Find out* → "Find". *Go on* → "Continue". (Some two-word verbs are in the dictionary as approved, for example MAKE SURE.)
- 9.4 — If step 1 says "Push the START button", step 9 does not say "Press Start" or "Hit the start key".

## 10. Grammar guidance (GR)

Issue 9 has eight topics of guidance after the rules.

| Topic | Guidance |
|---|---|
| GR-1 *that* | Keep the conjunction "that": "Make sure that the door is locked." |
| GR-2 *with* | Use "with" for the tool or the thing that goes together, and make the relation clear. Do not use "with" for a cause ("With the power off, …" → "When the power is off, …"). |
| GR-3 Pronouns | Use a pronoun only when its noun is clear and near. If there is doubt, repeat the noun. |
| GR-4 *this* | Use "this" with a noun: "This procedure…", not "This removes…". |
| GR-5 False friends | Be careful with words that look like a word in another language but have a different meaning (*actual* ≠ current, *eventually* ≠ possibly, *control* ≠ check). |
| GR-6 Latin abbreviations | Do not use *e.g., i.e., etc., via, vs.* Write "for example", "that is", "and other…", "through", "compared with". |
| GR-7 Inclusive language | Use gender-neutral words: "the technician… they", "personnel", not "he" / "manpower". |
| GR-8 Possessive | Use the possessive form ('s) only for persons or organizations, and only if the result is clear. For things, use "of": "the cover of the pump" or the TN "the pump cover". |
